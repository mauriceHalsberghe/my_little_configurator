# My Little Configurator - AirFryer

## Project

An interactive 3D configurator that allows users to customize an air fryer by changing its colors, materials, and components. The 3D model updates in real time, providing an intuitive and dynamic user experience.

## Technologies

- React
- React Three Fiber
- Drei

## Options

### Material
Matte / Gloss

### Color
Black / White / Pink / Blue

### Trays
Single / Double

### Interface
Analog Buttons / Digital Screen
